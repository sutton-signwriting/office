From interest to access

A careful path to the future app

Pre-registration is an interest list, not an authenticated account. The later registration service will make that transition explicit.

  1. Available now

    Join the interest list

    Email register@signwriting.org. This records interest separately from future application users.

  2. Planned

    Receive an invitation

    When register.signwriting.org is ready, pre-registered people can receive an email with a unique invitation key.

  3. Future

    Activate app access

    Redeem the invitation through registration to activate eligible features and usage allowances for app.signwriting.org and related api.signwriting.org services.

The invitation key should be a one-time registration credential. The app and API should issue separate, revocable authentication tokens after activation.
